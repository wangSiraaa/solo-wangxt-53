# 公益仓库离线扫码装箱与交接清单系统

一台**离线电脑**连续扫描捐赠物资：边评估成色边装箱、生成交接清单。
纯前端 **Svelte 4 + TypeScript + Vite**，扫码用 **ZXing（@zxing/browser）**，
数据全部在本机 **IndexedDB**，**无后台、无网络请求**。

## 启动（离线方式）

```bash
npm install          # 首次（联网机器上执行，或把整个工程目录拷过去）
npm run dev          # 开发：http://127.0.0.1:5173
# 或
npm run build        # 产物在 dist/，可用任何静态服务器/文件方式打开
npm run preview
npm test             # 30 个测试（vitest + fake-indexeddb）
npm run check        # svelte-check 类型检查
```

> 摄像头要求 https 或 localhost；用 `127.0.0.1` 访问即可。无摄像头/无权限时
> 系统自动降级到键盘（扫码枪等价于键盘回车）和文件导入，业务不中断。

## 数据模型与规则一览

- **Item（物品）**：条码为主键、全局唯一。重复扫描只定位原物品并累加 `scanCount`，
  日志记 `RESCAN`，**绝不产生第二份库存**。
- **Box（箱）**：归属一个机构，带「限收品类 + 最高污损等级」。
- **Organization（机构）**：授权品类 + 可接收最高污损等级。
- 装箱必须同时通过：**机构品类、机构成色、箱品类、箱成色、高价值复核结论**五类检查，
  任一不过逐条列出原因（`src/lib/rules.ts: validatePack`）。
- 高价值物品须先复核（可多次追加，以最后一条结论为准）。
- 交接 = 逐件勾检 + 每件仍适配，全部满足才锁定。锁定后清单只读，
  错误只能走**退回（RETURN）**，交接与退回记录都保留。
- 操作日志（`logs`）**只追加**：撤销 = 追加 `REVERT` 补偿记录，不删历史行；
  扫码之后若已追加复核，撤销被直接阻止，**复核记录不会被误删**。
- **移箱**在单个 IndexedDB 事务内同时改物品、来源箱（清勾检）、目标箱、日志，
  目标箱校验失败整笔回滚（`src/lib/actions.ts: moveItem`）。

## 三个预置案例（首次打开自动载入演示数据）

演示数据可在「清单/工程导出」页随时 **重置为演示数据**。

### 案例 1：摄像头不可用
1. 打开「扫码队列」，勾选 **「模拟摄像头不可用（离线演练）」**，点「启动摄像头扫码」；
   也可不勾选直接在没有摄像头的机器上点启动。
2. 出现黄色降级横幅，说明结构化原因（无设备/权限拒绝/非安全上下文），
   **键盘录入框自动可用**：输入条码回车即入队。
3. 「文件导入」页可继续批量导入，队列/装箱/交接/导出全部不受影响。
   规则覆盖见 `src/test/scanner.test.ts`（NO_MEDIA_API / PERMISSION_DENIED / NO_DEVICE）。

### 案例 2：重复扫描定位原物品
1. 队列页键盘输入 `6901001` 回车 —— 该码是箱 A-01 内已复核的儿童羽绒服。
2. 提示「重复条码…已定位原物品，已在【箱 box-a01】内，未新增库存」；
   连扫 N 次，库里始终只有 1 件，`scanCount` 增加，日志多一条 `RESCAN`。
3. 「文件导入」载入 `sample-import.csv`：其中 `6901001` 与库内重复，
   结果区把它归入“重复（未入库）”。

### 案例 3：一箱混入不适配物品
1. 切到「箱内明细/交接」选 **A-01**（爱华福利院：仅衣物、成色 ≤1）。
2. 队列中的 **毛绒玩具（污渍）6901003**：品类 toy、成色 3。预检列直接标红：
   “该箱仅收纳限定品类…”“成色 3级 超出箱上限 1级”“超出机构上限”，装入按钮禁用。
3. 即使物品已在箱内，交接区也**逐件列出**每件状态：未勾检 / 不适配，
   必须每件勾检且 0 阻断项，「整箱交接并锁定」才可点 —— 不是仅靠一个禁用按钮。
4. 箱 C-03 是**已交接锁定**样例：不能再编辑；点「交接有误·退回处理」，
   填原因后解锁修正，HANDOVER/RETURN 两行日志都保留。

### 撤销连续扫码（不毁复核）
- 队列物品行有「撤销扫码」：仍在队列、其后无复核记录才允许；
- 对已复核的高价值物品（先在队列页给它加复核再试）会被阻止并提示原因；
- 已装箱物品须先取出。撤销后物品消失，但 SCAN 原行保留、新增 REVERT 行。

## 导出物（全部离线生成）

- **待交接清单 HTML** 与 **已交接清单 HTML**：两类文件分开，已交接文件带
  「🔒 已交接 · 锁定」标识与接收人；可直接浏览器打印签字。
- **单箱清单**：箱详情页「导出本箱清单」。
- **工程快照 JSON**（`charity-warehouse/v1`）：含机构/物品/箱/完整日志，
  在另一台离线电脑的「恢复工程快照」即可重新打开整个工程。
